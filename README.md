# Electricity Consumption Forecasting

This repository contains a complete machine learning workflow for predicting hourly electricity consumption. It uses time-series features, lag variables, and rolling statistics to forecast energy usage.

## Project Overview

- **Goal**: Predict next-hour electricity consumption (kWh) based on historical data.
- **Approach**: Feature engineering combined with Machine Learning regression models.

## Repository Structure

- `Electricity Consumption Forecasting.ipynb`: The main Jupyter Notebook containing the entire end-to-end pipeline: data loading, feature engineering, model training, evaluation, and visualizations.
- `electricity.csv`: The hourly electricity usage dataset (required to run the notebook).
- `electricity_forecaster.pkl`: The final trained and serialized machine learning model generated by the notebook, which can be loaded for future inferences without retraining.

## Feature Engineering

To make standard ML models work with time-series data, the following features are engineered from the timestamps and target values:

1. **Temporal Features**: Extracting `hour`, `day`, `weekday`, and `month` to capture daily, weekly, and seasonal patterns.
2. **Lag Features**: Creating `lag1`, `lag2`, and `lag3` to allow the model to look at the immediate previous hours of energy consumption.
3. **Rolling Statistics**: Calculating a 3-hour moving average (`rolling_mean`) to capture short-term trends and smooth out fluctuations.

## Models Evaluated

The notebook evaluates and compares the following algorithms:
1. **Ridge Regression**: A linear model with L2 regularization (tuned via `GridSearchCV`).
2. **Random Forest**: An ensemble method using multiple decision trees.
3. **Gradient Boosting**: A sequential ensemble method.

## Getting Started

### Prerequisites

You will need Python installed along with the following libraries:
- `pandas`
- `numpy`
- `matplotlib`
- `scikit-learn`
- `jupyter` (to run the notebook)

### Running the Notebook

1. Clone this repository.
2. Ensure you have the required libraries installed (`pip install pandas numpy matplotlib scikit-learn jupyter`).
3. Ensure the `electricity.csv` file is in the same directory as the notebook.
4. Launch Jupyter Notebook or open it in VS Code:
   ```bash
   jupyter notebook
   ```
5. Open `Electricity Consumption Forecasting.ipynb` and run the cells sequentially.

## Evaluation Metrics

The models are evaluated using standard regression metrics:
- **MAE (Mean Absolute Error)**: Average absolute difference between predicted and actual values.
- **RMSE (Root Mean Squared Error)**: Penalizes larger errors.
- **R² Score**: The proportion of variance in the target explained by the model.
